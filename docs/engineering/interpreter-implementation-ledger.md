## P1 source-free custody law before production

Classification: derived affine ownership and deliberate Bombay diagnostic policy. An attempted accepted item may discharge a receipt or retain its exact accepted value for terminal custody. Rejection, blocking, corruption, and untouched items keep their complete request. Source-free collection removes only discharged receipts and reports `Retained` for any nonempty residual; it never admits a source input. A retained accepted value remains retained on a repeated offer. In a product, a retained earlier lane does not prevent later source admission. The caller sees the existing `SourceCustody` sum and does not need a new wrapper.

The pre-edit external witness is `tests/interpreter-contract/tests/source_free_custody.rs`. It requires terminal `DiagnosticAccepted::Terminal(Box<str>)` to survive two offers, delivered diagnostics to discharge, and every source-free failure alternative to return its exact owned input. It must fail on the original unconditional `Exhausted(self)` implementation. The lower-order composition witnesses are core `source_settlement_admission`, generated creation custody, and Actors diagnostic tests; the later real Driver witness will prove continuing turns and retirement.

Aggregate-drift precheck: this edit changes no actor aggregate control state, subordinate stored state, transition branch, module, or public type. `DiagnosticAccepted` remains the accepted-value sum; the current diagnostic payload is needed at retirement only in its `Terminal` variant. The core vector is an ordered residual product, not an actor state machine. The proposed method owns one item-specific discharge decision, and no semantic boolean or positional caller syntax is introduced. Cross-checks: `actor-transition-algebra.md`, `atomic-runtime-settlement.md`, `behavior-layer-laws.md`, and all five normalized atomic laws. Disposition: `pass` for the pre-edit model, pending the failing external witness.

The Nix-pinned external fixture compiled on the prior design and failed all three focused tests for the intended law: terminal diagnostic returned `Exhausted`, source-free rejection/blocked/corrupt/untouched returned `Exhausted`, and 100 delivered diagnostics remained in an `Exhausted` vector instead of discharging. This is the red regression for P1. The fixture's first compilation required only a local test type annotation; no production API was changed to make the regression compile.
