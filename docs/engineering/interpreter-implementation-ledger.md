Rejection, blocking, corruption, and untouched items keep their complete request. Source-free collection removes only discharged receipts and reports `Retained` for any nonempty residual; it never admits a source input. A retained accepted value remains retained on a repeated offer. In a product, a retained earlier lane does not prevent later source admission. The caller sees the existing `SourceCustody` sum and does not need a new wrapper.
