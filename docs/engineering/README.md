# Engineering records

These documents preserve the design campaign behind Bombay Behavior: research
classification, candidate type inventories, acceptance targets, verification
evidence, downstream-impact analysis, and audit results. They remain published
for traceability, but they are not an additional public API surface.

The canonical contracts, actor catalogue, normalized aggregate laws, current
crate documentation, and production types govern whenever terminology or an
intermediate proposal in these records differs from the retained design.
